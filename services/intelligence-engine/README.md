# YATRA Intelligence Engine (`services/intelligence-engine`)

Multilingual assistance, cognitive simplification, and incident interpretation powered by **Google Gemini 2.5 Flash**.

## Core Responsibilities

1. **Multilingual Transit Explanations:** Translates route changes, accessibility statuses, and boarding advice into Hindi, Punjabi, Urdu, and English.
2. **Cognitive Simplification:** Summarizes transit delays into concise, accessible instructions for passengers with cognitive disabilities.
3. **Structured Incident Triage:** Classifies unstructured commuter feedback into actionable defect tickets (e.g. Broken Hydraulic Ramp, Obstructed Curb Cut) with assigned severity.
4. **Deterministic Isolation:** Strictly prohibited from performing numerical headway scheduling or safety-critical dispatch calculations.
