# YATRA Notification Service (`services/notification-service`)

Dual-modality push notification and audio synthesis dispatcher.

## Core Responsibilities

1. **Dual-Modality Dispatch:** Sends concurrent visual banners and auditory speech synthesis cues for passenger and driver alerts.
2. **Audio Cue Generation:** Prepares standardized phonetic stop announcements (Hindi & English) for in-cab DriverAssist speakers.
