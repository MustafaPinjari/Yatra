# YATRA — Multi-Agent Instructions & Unslop Enforcement

## Mandatory Agent Instruction: Unslop Skill Enforcement

Before writing or editing any English text intended for human readers, load and apply the Unslop skill (`~/.gemini/config/skills/unslop/SKILL.md`). Follow its complete instructions and reference materials. Do not merely replace individual AI-sounding words. Apply its typography, vocabulary, structural and epistemic principles.

---

### Level 1: Typography and Mechanics
- **Sentence Case Everywhere**: Use sentence case for UI labels, table headers, tabs, and buttons instead of ALL-CAPS tracked text.
- **No Exclamation Marks**: Interface copy must never use exclamation marks (`!`).
- **No Trailing Periods on Short Strings**: Headings, subheads, labels, buttons, captions, and short status pills end without a period. Only multi-sentence body paragraphs retain periods.
- **Tabular Numerals**: Numbers in tables and metric strips use tabular figures and uniform formatting.

---

### Level 2: Vocabulary and Rhetoric
- **Eliminate Hype and Buzzwords**: Strip "seamless", "revolutionize", "supercharge", "unlock", "empower", "effortless", "game-changing".
- **Contextual Headings**: Replace empty greetings with contextual task descriptions.
- **Concise Placeholders**: `Search routes or stops`, not wordy conversational text.
- **Verifiable Metrics**: Quantify changes relative to baseline (e.g., `+1.8% vs last quarter`).

---

### Level 3: Structure and Epistemics
- **Audience Alignment**:
  - Passengers: clear, direct, practical.
  - Accessibility Users: dignified, respectful, barrier-focused.
  - Drivers: minimal distraction, concise alerts.
  - Operators: exact telemetry, headway, and status codes.
  - Government: verifiable compliance metrics, audit trails.
  - Developers: rigorous technical accuracy.
- **Zero Fabrication**: Do not invent metrics, routes, or guarantees.

---

### Strict Code Protection
Never modify variable names, function names, database columns, JSON keys, API parameters, or test expectations unless specifically required by the user.
